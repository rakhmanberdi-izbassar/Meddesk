# Өтінім мәртебесі және басшылыққа арналған есеп

MedDesk 0.5.1. Бұл мүмкіндік IT маманы мен әкімшіге арналған.

## Мәртебені өзгерту

1. [MedDesk](http://localhost:8080) жүйесіне IT маманы немесе әкімші ретінде кіріңіз. Демо IT аккаунты: `engineer@meddesk.test`; құпиясөзі жергілікті `.env` ішіндегі `DEMO_ENGINEER_PASSWORD` мәнінде. `employee@meddesk.test` аккаунтының рөлі — қарапайым қызметкер, ол басқа өтінімдерді басқара алмайды.
2. **Өтінімдер** бөлімінен өтінімді ашыңыз.
3. **Өтінім мәртебесі** бөлімінде **Жаңа күй** таңдаңыз және **Күйді өзгерту** батырмасын басыңыз.

Жұмыс реті: **Жаңа → Орындалуда → Шешілген → Жабылған**. Жауап қажет болса, орындалудағы өтінімді **Қызметкер жауабы күтілуде** күйіне ауыстыруға болады. Шешілген өтінімге жұмыс жалғасса, оны **Орындалуда** күйіне қайтаруға болады. Жабылған өтінімді тек әкімші арнайы қайта ашады. Өтінім иесі шешімін растап, шешілген өтінімді жаба алады.

Әр өзгеріс өтінім тарихында сақталады. Басқа адам өтінімді қатар өзгерткенде, бет ескіргені туралы хабар көрсетіледі; деректерді жаңартып, қайта таңдаңыз.

## Excel немесе CSV жүктеу

1. [Өтінімдер](http://localhost:8080/tickets) бөлімін ашыңыз.
2. Қажетті іздеу, мәртебе, басымдық, санат, бөлім және жауапты маман сүзгілерін таңдаңыз. **Менің өтінімдерім** тек өзіңіз жіберген өтінімдерді көрсетеді; ол сізге тағайындалған өтінімдер дегенді білдірмейді. Өзіңіз орындаған жұмысты көру үшін жауапты маман сүзгісінен өзіңізді таңдаңыз.
3. Айлық немесе басқа кезеңнің есебі үшін өтінімнің **құрылған күнінен** және **құрылған күніне дейін** өрістерін толтырып, **Сүзгілерді қолдану** батырмасын басыңыз. Екі шекара күні де есепке кіреді. Кезең 366 күннен аспайды. Күндер бос болса, барлық уақыттағы өтінімдер алынады.
4. **Басшылыққа арналған есеп** аймағында **Excel жүктеу** немесе **CSV жүктеу** батырмасын басыңыз. Файл интерфейстің таңдалған тілінде дайындалады: қазақша немесе орысша.

Экспорт барлық беттегі сүзгіге сәйкес өтінімдерді қамтиды. Бір файлдың шегі — 5000 өтінім және 20 MiB. Шек асса, жүйе кезеңді немесе сүзгілерді тарылтуды сұрайды; өтінімдерді үнсіз қысқартпайды.

Күн шекаралары клиника баптауларындағы уақыт белдеуіне сүйенеді (бастапқысы — `Asia/Almaty`); оны есеп сүзгісінде өзгертуге болады. Сүзгідегі кезең нақты жұмыс атқарылған күнді емес, өтінім құрылған күнді қамтиды. Сондықтан бұрын құрылған, осы айда шешілген өтінім айдың құрылу кезеңіне кірмейді; барлық уақытты немесе кеңірек кезеңді таңдаңыз.

## Есеп нені көрсетеді

Excel файлының жоғарғы бөлігінде клиника атауы, есептің дайындалған уақыты, уақыт белдеуі, кезеңі, қолданылған сүзгілер және қорытынды көрсетіледі. Кестеде өтінім нөмірі мен тақырыбы, өтінім беруші, бөлім, санат, басымдық, қазіргі мәртебе, жауапты маман, құрылған/жаңартылған/шешілген уақыты және шешуге кеткен сағат бар.

- **Барлығы** — таңдалған өтінімдердің саны.
- **Ашық** — жаңа, орындалуда және қызметкер жауабы күтілуде күйлерінің қосындысы.
- **Шешілген** — шешілген және жабылған өтінімдердің қосындысы.
- **Жабылған** — шешілгендердің ішіндегі жабылған өтінімдер.
- **Орташа шешілу уақыты** — қазіргі кезде шешілген немесе жабылған өтінімдердің бастапқы құрылу уақытынан қазіргі шешілу уақытына дейінгі орташа сағат. Қайта ашылған өтінім шешілгенге дейін бұл есептеуге кірмейді; қайта шешілсе, бастапқы құрылған уақыт қолданылады. Өлшем жоқ болса, ұяшық бос қалады.

CSV файлы тек баған тақырыптары мен өтінім жолдарын береді; қорытынды үшін Excel таңдаңыз. Excel-де сандар мен күндер жеке дерек түрінде сақталады, баған сүзгісі мен бекітілген тақырыптар бар. CSV UTF-8 BOM арқылы қазақша/орысша мәтінді сақтайды; импорт кезінде бөлгіш ретінде үтірді таңдауға болады.

Файлдарға өтінім сипаттамасы, талқылаулар, ішкі пікірлер, тіркемелер, email және құпиясөздер кірмейді. Формулаға ұқсайтын мәтін орындалатын формулаға айналмайды. Есеп жүктеу тек IT маманы мен әкімшіге рұқсат етіледі; қарапайым қызметкерге бұл батырмалар көрсетілмейді және API рұқсат бермейді.

## API

`GET /api/v1/tickets/export` — сессиямен қорғалған жүктеу. Параметрлер: `format=xlsx|csv`, `locale=kk|ru`, `q`, `status`, `priority`, `category_id`, `department_id`, `assignee_id`, `mine`, `from`, `to`, `timezone`. Формат берілмесе — Excel, тіл берілмесе — қазақша, күндер берілмесе — барлық уақыт. `limit` және `offset` экспорт үшін қабылданбайды.

Өтінім тізіміндегі `from`, `to`, `timezone` параметрлері экспортпен бірдей күн шекараларын қолданады. Өтінімдер мен Excel қорытындысы бір PostgreSQL snapshot-тан алынады. Мүмкіндік дерекқордың жаңа миграциясын талап етпейді; схема нұсқасы — 4.

20 MiB шегі дайын файлға және Excel кестесінің сығылмаған XML көлеміне қолданылады. Шек асқанда API `409 export_limit` қатесін қайтарады; файлдың бір бөлігі жіберілмейді. Сұрау уақыты аяқталса да, сервер жартылай файлдың орнына JSON қатесін береді.

## Тексеру нәтижесі

2026-10-12 күні:

- Go `-race` тесттері және `go vet` өтті. Мәртебе рұқсаттары, экспорт шектері, локализация, формулаға ұқсайтын мәтін және файл/timeout жауаптары тексерілді.
- Интерфейстің typecheck, 110 тесті және build өтті; шек туралы мәтін нақтыланғаннан кейін өтінім бетінің 31 тесті қайта өтті.
- Оқшауланған PostgreSQL 18-де толық интеграциялық тесттер екі рет өтті (262.862 және 278.609 секунд), миграция `up/down/up` және seed қайталауымен бірге. Тізімнің 20 жолдық бетіне қарамастан экспортта 25 сәйкес өтінім бар екені, IT маманының мәртебені өзгертуі, нақты қорытынды, уақыт белдеуі/DST, рөл ауысуы, 5001 өтінімге толық бас тарту тексерілді.
- Соңғы жол биіктігі түзетуімен экспорттың нақты HTTP/PostgreSQL workflow тесті бөлек қайта өтті. Жасанды XLSX Artifact Tool және тәуелсіз Excel оқу құралында ашылды; күндер, сандар, қорытынды, баған сүзгісі, бекітілген тақырып және формуласыз мәтін тексерілді. Соңғы файл LibreOffice-та ашылып, оның баспа көрінісі тексерілді.
- Жергілікті Docker қызметтері сау, API нұсқасы `0.5.1`. Gateway арқылы IT маманы/әкімшіге Excel және CSV, қызметкерге `403`, анонимге `401` тексерілді. Тексеру нақты өтінімдерді өзгертпеді.

Интерфейстің әрекеттері компонент тесттерімен тексерілді; нақты браузердегі визуалдық тексеру және Microsoft Excel-дің өзінде ашу орындалмады.
